# Relax 408｜408 习题组卷器

> 基于 Relax 408 1000 题制作的本地优先组卷与练习平台。无需账号、无需联网、无需安装 Node.js，双击即可在 macOS 浏览器中使用。

## 项目概览

Relax 408 是一套面向 408 计算机学科专业基础考试的本地练习工具。题库、题目截图、解析截图与 PDF 原册全部保存在本机，答题记录也只写入当前浏览器，不会上传到网络。

平台只包含选择题，不包含或生成大题。目前提供三种组卷方式：

| 组卷方式 | 适用场景 | 组卷逻辑 |
| --- | --- | --- |
| 真题结构 | 日常模考、熟悉科目配比 | 按 408 选择题 `11 + 12 + 10 + 7` 的科目结构和章节模板抽题 |
| 章节侧重 | 强化薄弱章节 | 约 70% 题量分配给手动选择的重点章节 |
| 内容匹配 | 复习当天学习内容 | 输入知识点后，优先匹配科目、章节、题干和解析中的关键词 |

## 核心功能

- **完整本地题库**：共 1,576 道选择题，覆盖数据结构、计算机组成原理、操作系统和计算机网络。
- **多种卷型**：支持全科套卷、半套卷以及四门单科卷。
- **灵活筛题**：可按没做过、未掌握的错题、全部错题、已做过和已收藏等状态组卷，多选时取并集。
- **模考答题**：支持计时、题号导航、暂存、标记待检查、收藏和统一交卷。
- **自动结算**：交卷后展示正确率、客观分、逐题结果与下一道错题入口。
- **错题管理**：错题自动记录，后续答对后可从“未掌握”列表中移出。
- **原册解析**：题目或解析出现复杂公式、特殊符号和图表时，直接展示对应 PDF 截图，避免转文字乱码。
- **截图放大**：解析截图支持点击查看大图和自由缩放。
- **本地数据**：练习记录、错题、收藏和设置均保存在浏览器本机。
- **一键清零**：出厂设置可清除全部本地学习记录并恢复初始状态。

## 快速开始

### 方式一：下载完整版本

1. 在仓库右侧打开 **Releases**。
2. 下载最新版 `Relax408本地版.zip`。
3. 解压后双击 `启动 Relax408.command`。
4. 浏览器会自动打开 [http://127.0.0.1:4080/](http://127.0.0.1:4080/)。
5. 使用期间保持启动窗口开启；关闭窗口即停止本地服务。

### 方式二：克隆仓库

```bash
git clone https://github.com/Tenzen-a10/408-exercise-paper-generator.git
cd 408-exercise-paper-generator
open "启动 Relax408.command"
```

首次启动时，如果 macOS 阻止运行，请右键点击 `启动 Relax408.command`，选择“打开”，然后再次确认。

## 数据保存与隐私

平台固定运行在 `127.0.0.1:4080`，并且只监听本机回环地址，局域网和互联网中的其他设备无法访问。

答题数据保存在浏览器的本地存储中。为避免记录丢失：

- 建议始终使用同一个浏览器打开平台。
- 不要清除 `127.0.0.1:4080` 的网站数据。
- 更换浏览器不会自动迁移原浏览器中的学习记录。
- 点击“出厂设置”会清空全部答题记录、错题、收藏和设置。

## 常见问题

### 为什么不能直接双击 `index.html`？

浏览器的本地文件安全规则会限制题库和 PDF 资源读取。启动脚本会在本机开启一个仅供本机访问的小型服务，从而让页面完整运行。

### 是否需要 Codex 或 ChatGPT 会员？

不需要。平台生成完成后就是独立本地软件，运行过程与 Codex、ChatGPT 及其会员状态无关。

### 可以断网使用吗？

可以。下载并解压完整版本后，题库、截图、PDF 和页面资源都在本机。

### 为什么有些题目直接显示截图？

部分题目包含复杂公式、特殊符号或图表，文本转换容易出现乱码。平台对这类题目直接使用原册对应区域截图，确保内容完整且准确。

### 启动时提示端口 4080 被占用怎么办？

先双击 `停止 Relax408.command`，然后重新启动。如果仍然提示被占用，请关闭其他使用 4080 端口的本地程序后再试。

### 如何彻底重置学习记录？

点击页面右上角的“出厂设置”，确认后即可恢复到首次使用状态。此操作不可撤销。
